# Cat sprite assets

`cat-orange-white.png` is the shipped sprite atlas. It was **procedurally generated by
`src/Petty.Assets`** (a deterministic pixel renderer in this repository), not by an AI
image model — no image-generation tool was available in the build environment. Every
pixel is placed by code in `CatSpriteRenderer.cs` / `Animations.cs`, so the artwork is
reproducible, versionable and free of AI artefacts.

## Layout

- Atlas: `512x384`, 8 columns x 6 rows of `64x64` cells, row-major.
- Frames: 48 total, `cat-orange-white.json` describes each clip.
- Transparent background with a real alpha channel (`color type 6`, 8-bit RGBA).
- 7-colour palette, hard edges, no anti-aliasing (alpha is only 0 or 255).
- `groundRow: 52` — the row (including the 1px outline) that touches the ground.

| Clip | Frames | Cells | FPS | Loop |
|---|---:|---|---:|---|
| idle | 4 | 0-3 | 5 | yes |
| walk | 8 | 4-11 | 9 | yes |
| run | 8 | 12-19 | 14 | yes |
| eat | 6 | 20-25 | 7 | yes |
| sleep | 4 | 26-29 | 3 | yes |
| play | 8 | 30-37 | 11 | yes |
| tired | 4 | 38-41 | 4 | yes |
| exit | 6 | 42-47 | 9 | no |

The ball and the food bowl are **not** part of the atlas: the app draws both as separate
objects, so the play and eat animations stay reusable.

## Regenerate

From the repository root:

```powershell
dotnet run --project src/Petty.Assets -c Release
```

or, with the helper script:

```powershell
./scripts/generate-assets.ps1
```

This rewrites the atlas, the metadata, all 48 individual frames in `frames/`, and the
2x previews in `preview/`. To check the existing files without regenerating:

```powershell
dotnet run --project src/Petty.Assets -c Release -- --verify
```

## Validation

The generator re-decodes the written PNG and fails the run if any of these break:

- atlas size differs from `columns * frameWidth` / `rows * frameHeight`;
- any pixel is semi-transparent or outside the palette;
- a frame is empty or touches the cell edge;
- a standing clip (`idle`, `walk`, `eat`, `tired`, `exit`) is not on `groundRow`;
- the walk loop jumps more than 2.5x a normal frame step;
- metadata is invalid (missing clip, overlapping clips, frames outside the grid).

Automated tests additionally verify the shipped metadata, the PNG header (real RGBA),
frame counts and the extracted frames (`tests/Petty.Tests/SpriteAssetFileTests.cs`).
