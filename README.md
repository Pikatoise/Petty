## At home on your desktop

Choose a companion, give it a name and let it settle in. Petty lives on the desktop
behind your normal windows, with a small tray menu for settings and exit.

| | What you get |
|---|---|
| 🐾 **Your own companion** | Eight breeds, five coats each, one active pet and a name you choose. |
| 🎾 **Small everyday moments** | Wandering, naps, a ball to play with and a little petting. |
| 🥣 **A place to eat** | A refillable, draggable bowl; a hungry pet finds its way over. |
| 🪟 **Desktop manners** | Transparent pixels pass clicks through. No taskbar button or always-on-top pet. |
| 💾 **A familiar face** | Identity, needs and bowl placement survive restarts. |
| 🌐 **Two languages** | Russian and English, with optional Windows autostart. |

Runs locally: no accounts, cloud services, runtime AI or network connection required.
All pet sprites are original procedural pixel art generated by the project's C# asset tools.

## Quick start

Download the Windows app from the [latest GitHub release](https://github.com/Pikatoise/Petty/releases/latest).

**Requirements:** Windows 11 x64 and
[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0).
Windows 10 is supported on a best-effort basis. Petty currently uses the primary monitor.

1. Install the **Desktop Runtime** if it is not already available.
2. Save `Petty.exe` in a folder you want to keep.
3. Run `Petty.exe`, watch or skip the four-page introduction, then choose a breed
   and coat and name your pet. Reopen **Tutorial** from Settings at any time.

The introduction appears automatically only for new users. Completing or skipping
it is remembered even if pet creation is canceled afterward. Closing the first-run
introduction exits Petty and offers it again next time; closing a replay leaves the
current pet running.

> **One EXE, including artwork and license notices.**
> The .NET Desktop Runtime is installed separately. Bundled sprites are unpacked
> into a build-specific cache under `%TEMP%/Petty/bundled` when first loaded.

## Meet the pets

Every breed has **five selectable coats**, for **40 appearances** in total.

| Cats | Dogs |
|---|---|
| British Shorthair | Cardigan Welsh Corgi |
| Maine Coon | Dachshund |
| Siamese | Border Collie |
| Persian | Siberian Husky |

Use the coat arrows in the creator to cycle through appearances. Names can be changed
later; replacing a pet opens the creator again and requires confirmation.

## Everyday controls

| Action | How it works |
|---|---|
| **Play or pet** | Hover over your pet and choose an action. Sleeping pets can be petted; Play becomes available when awake. |
| **Feed** | Click the bowl to add 25 food, up to 100. Clicks during pouring are ignored. |
| **Move the bowl** | Drag it to a new position while the pet is not eating. Dragging does not add food. |
| **Rename or replace** | Open Settings from the tray. Names save automatically; replacement requires confirmation. |
| **Exit** | Use the tray menu. Your pet walks away before the application closes. |

Closing Settings leaves Petty running. Hunger and happiness change while the application
runs, including during pet naps. Needs freeze while Petty is closed or the computer sleeps.
Petting pauses a nap and then lets it resume.

## Your data stays yours

- **Saves:** `%LOCALAPPDATA%\Petty`. Application files and personal data are separate.
- **Autostart:** enabled by default after successful startup; toggle it in Settings.
- **Move:** move `Petty.exe`, then launch it once to repair its autostart path.
- **Update:** exit through the tray and replace `Petty.exe`. Keep your data folder.
- **Uninstall:** disable autostart, exit Petty and delete its application folder.

Updates are manual. Petty does not include an automatic updater.

## Development

Build on Windows with **.NET SDK 10**. From the repository root:

```powershell
dotnet build Petty.slnx -c Release
dotnet run --project src/Petty.App
```

### Checks

```powershell
dotnet test Petty.slnx -c Debug
dotnet test Petty.slnx -c Release

dotnet run --project scripts/ContentVerification -c Release
dotnet run --project src/Petty.Assets -c Release -- --verify

# Close other Petty instances before running the Windows harness.
dotnet run --project scripts/WindowsReleaseVerification -c Release

# Optional isolated tutorial startup/replay scenarios:
$env:PETTY_VERIFY_TUTORIAL = '1'
dotnet run --project scripts/WindowsReleaseVerification -c Release
Remove-Item Env:PETTY_VERIFY_TUTORIAL
```

### Portable build

```powershell
./scripts/publish-portable.ps1
# Optional ZIP for distribution:
./scripts/publish-portable.ps1 -Zip
```

The output contains only `Petty.exe` and requires the .NET 10 Desktop Runtime x64.
Desktop sprites scale continuously with the primary monitor's resolution, from 1× at
1280×720 to 3× at 2560×1600 (about 1.82× at 1920×1080 and 4.27× at 3840×2160).
The scale follows the smaller width/height growth from those reference resolutions,
with a 1× minimum and no upper cap; final window dimensions round to screen pixels. A display change
updates pet and props together, with nearest-neighbor rendering at every size.
Interaction actions are larger on compact displays while retaining their reference size
at 2560×1600. Ordinary dialogs follow Windows DPI and fit the monitor's work area;
short windows scroll, and the creator stacks its preview above the form when narrow.
